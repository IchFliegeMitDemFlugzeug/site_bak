БТС — оригинальный прототип сайта в духе современной high-tech продуктовой подачи.

ВАЖНО
-----
Этот проект НЕ является копией skydio.com.
В архив не включены код, изображения, видео, шрифты, логотипы, тексты или другие ресурсы Skydio.
С нуля воспроизведены только общие композиционные принципы: крупная типографика, чередование светлых и тёмных сцен, нумерованные направления, sticky/scroll storytelling, горизонтальная scroll-секция и микровзаимодействия.

ЗАПУСК
------
1. Распаковать архив.
2. Открыть PowerShell в папке bts_skydio_spirit.
3. Выполнить:
   py -m http.server 8080
4. Открыть:
   http://localhost:8080

ФАЙЛЫ
-----
index.html          — структура страницы и весь текст.
assets/styles.css   — вся графика, адаптив и визуальные эффекты.
assets/main.js      — scroll-анимации, reveal, параллакс и горизонтальный процесс.

ЧТО ЗАМЕНИТЬ ДЛЯ РЕАЛЬНОГО САЙТА
--------------------------------
- Поставить утверждённый логотип БТС вместо текстового прототипа.
- В блок "ФОТО ИЗДЕЛИЯ" вставить исходную фотографию бака без генеративной перерисовки технического объекта.
- Уточнить технические формулировки и характеристики.
- Указать рабочие контакты.
- При необходимости добавить реальные фото производства, испытаний и интеграции.

ТЕХНИКА
-------
Никаких внешних JS/CSS библиотек нет.
Никаких внешних картинок нет.
Никаких чужих шрифтов нет.
Сайт можно полностью разместить на собственном nginx/Apache или обычном статическом хостинге.
